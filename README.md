# De Groot — Umbrel community app store

Private-use app store for one umbrelOS device. Contains:

- **degroot-spotweb** — Spotweb (jgeusebroek/spotweb + MariaDB) as a newznab indexer for Prowlarr.

Add in umbrelOS: App Store → ⋯ → Community App Stores → paste this repository URL.
No credentials live in this repository; the database password is derived from the per-app seed on the device.
